# Changelog

## 1.0.0 — Initial Release

- Expanded the original game into a three-level campaign
- Added horizontal and vertical enemy patrol patterns
- Added rotating hazards with visible-shape collision detection
- Added required coin collection and goal validation
- Added level and campaign completion states
- Added level and campaign timers that pause on completion
- Replaced negative scoring with level and total death counts
- Added restart and new-campaign controls
- Added dependency-free collision smoke tests
- Added reproducible scripts for building and running a packaged JAR
- Added continuous integration and build artifacts
- Removed unused legacy geometry scaffolding
